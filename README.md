# 🎬 APULA-FLIX - Multi-Platform Streaming Web

APULA-FLIX adalah platform web streaming modern dengan antarmuka bergaya **Netflix UI** yang dirancang khusus untuk memutar ribuan judul drama pendek (*short drama*), film, serial, anime, dan donghua dari **14+ platform streaming** secara gratis, responsif, dan tanpa buffering.

---

## ✨ Fitur Utama

- 🎭 **Multi-Platform Support**: Akses katalog dari DramaBox, DramaWave, LookSeries, GoodShort, DramaQueen, DonghuaQueen, ReelShort, Vigloo, FunDrama, HotDrama, Honey, BibiShort, ShortMax, dll.
- 📱 **Ultra Responsive Design**: Tampilan optimal di semua perangkat (Desktop, Tablet, & Smartphone dengan Mobile Bottom Navigation).
- ⚡ **Full Video Streaming**: Mendukung format **MP4 langsung** dan streaming adaptif **HLS ()** lengkap dengan multi-subtitle dan auto-play episode berikutnya.
- 🚀 **Serverless Cloudflare Edge**: Backend berjalan tanpa server (tanpa Python) menggunakan Cloudflare Pages Functions untuk bypass CORS dan caching edge cepat.
- 🎨 **Netflix Dark Theme**: Hero banner sinematik, kategori beranda/trending/sulih suara/VIP, pencarian real-time, dan pemutar video dengan episode drawer.
